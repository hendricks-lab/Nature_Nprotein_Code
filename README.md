# N Protein Condensate Mechanics and Membrane Interactions

This repository contains the code used to generate and analyze the data presented in the manuscript. It is organized into two main sections corresponding to the force–indentation experiments and physical modeling of condensate–membrane interactions.

## Repository Organization

### Force Indentation Analysis

Contains the code used to process and analyze force–indentation measurements of N protein condensates, including individual curve fitting and ensemble-average analysis.

This section was used to generate and analyze the data presented in:

- **Figure 2**
- **Extended Data Figure 4**

### Physical Modeling

Contains the physical modeling code used to investigate condensate–membrane interactions and generate and analyze the corresponding model results.

This section relates to:

- **Figure 4**
- **Extended Data Figures 8–9**
